# Roadmap

## Version 0.1

- Local CLI scanner.
- Markdown and JSON reports.
- GitHub Actions mutable ref checks.
- Broad token permission checks.
- Sensitive file hygiene checks.
- Release workflow risk checks.

## Version 0.2

- Better YAML location tracking.
- SARIF output for GitHub code scanning.
- Config file for rule severity and ignores.
- Additional release ecosystems such as Docker, Maven, and RubyGems.

## Version 0.3

- Optional AI-assisted explanations for findings.
- Pull request summary generation.
- Maintainer triage helpers for false positives and rule requests.
